# Diktuj artwork

`diktuj-icon.svg` is the app icon, `diktuj-logo.svg` the icon with the wordmark.
The Android versions are in `app/src/main/res/drawable/` and `mipmap-anydpi-v26/`.

The colors are those of the Sorbian flag: blue `#003DA5`, red `#DA291C` and
white. The microphone drawing is original work under the project's MIT license.

The wordmark is set in [Inter](https://github.com/google/fonts/tree/main/ofl/inter)
SemiBold (weight 650, optical size 32) and converted to outlines. Inter is
licensed under the SIL Open Font License, see
[third_party/inter/OFL.txt](../third_party/inter/OFL.txt).
